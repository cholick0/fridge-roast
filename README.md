A make.fun bounty entry: one line (146 characters) roasting a smart fridge,
written by a program (`main.ts`, Node 22) that writes the line to
`/output/entry.txt`.

## The line

> After last night's firmware update, my smart fridge's ice maker dispenses one cube at a time, slowly, like it's doing me a favor I didn't ask for.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The program self-checks the entry against the bounty gate (1–200 characters,
one line, not only white space) and verifies the file on disk byte-for-byte
before reporting success.
